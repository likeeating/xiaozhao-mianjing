# 雀巢面经汇总：1 个岗位的面试题

按岗位整理的雀巢近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 雀巢](https://mianjingku.com/gongsi/nestle)。

## 管培生（销售 / 市场 / IT 等方向）（校招）

- 收录：7 篇面经，55 道题
- 面试轮次：网申（英文简历 + 90 秒英文短视频 + 测评 / AI 面） → HR 电话面试 → AC（事业部介绍、英文自我介绍、群面与汇报） → Panel 面 / 1v1 面试 → 终面 · 事业部或区域负责人（部分岗位）
- 常考方向：英文表达、群面 / AC、求职动机、经历深挖、产品推销、销售认知
- 示例题：
  - 随机抽一款雀巢产品，结合产品特点用英文做自我介绍（2 分钟）。
  - 你们觉得刚才谁表现最好？你自己做得好的地方和不足各是什么？
