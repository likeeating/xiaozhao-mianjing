# 知乎面经汇总：3 个岗位的面试题

按岗位整理的知乎近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 知乎](https://mianjingku.com/gongsi/zhihu)。

## 后端开发（校招）

- 收录：7 篇面经，83 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面
- 常考方向：Redis ZSet、MySQL 日志与锁、主从与一致性、网络与操作系统、Go / Java 基础、场景代码分析
- 示例题：
  - ZSet 里的哈希结构是干什么用的？存 1000 个 int 大约占多少内存？
  - 网络波动导致同一用户多次下单，怎么保证一人一单（幂等设计）？
- 完整面经：[知乎后端开发校招面经](https://mianjingku.com/mianjing/zhihu-houduan-campus)

## 内容运营（校招）

- 收录：5 篇面经，49 道题
- 面试轮次：一面 · 业务面（简历 + 业务）
- 常考方向：实习深挖、平台理解、内容策略、达人与创作者运营、求职动机
- 示例题：
  - 平时用抖音、B 站、小红书吗？它们之间有什么不同？
  - 你会怎么说服某位达人入驻我们平台？
- 完整面经：[知乎内容运营校招面经](https://mianjingku.com/mianjing/zhihu-yunying-campus)

## 产品经理（校招）

- 收录：3 篇面经，28 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → 三面 · 综合面
- 常考方向：实习深挖、业务理解、竞品分析、增长与商业化、求职动机
- 示例题：
  - 过去小说大多是付费的，这几款产品的商业模式差在哪里？分别面向什么人群？
  - 作为产品负责人，体验 PM 和增长 PM 发生矛盾，你怎么解决？
- 完整面经：[知乎产品经理校招面经](https://mianjingku.com/mianjing/zhihu-chanpin-jingli-campus)
