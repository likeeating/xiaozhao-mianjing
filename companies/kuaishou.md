# 快手面经汇总：6 个岗位的面试题

按岗位整理的快手近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 快手](https://mianjingku.com/gongsi/kuaishou)。

## 产品经理（校招）

- 收录：8 篇面经，67 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 / 交叉面 → 三面 · 主管面（部分岗位） → HR 面
- 常考方向：实习深挖、产品分析、策略与指标、场景题、数据与 SQL、求职动机
- 示例题：
  - 快手和抖音有什么区别？
  - 如果这个模块的数据明显下降，你会从哪些角度定位问题？
- 完整面经：[快手产品经理校招面经](https://mianjingku.com/mianjing/kuaishou-chanpin-jingli-campus)

## 后端开发（校招）

- 收录：8 篇面经，131 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面 / 主管面 → HR 面
- 常考方向：Java 基础与并发、JVM、MySQL 与 Redis、Spring、计算机网络、手撕算法
- 示例题：
  - 核心线程 5、最大线程 10、队列容量 100、拒绝策略为丢弃：线程池刚创建时有几个线程？提交 6 个任务后呢？
  - 刷快手时刷到一个视频，从网络角度看，这个视频是怎么被获取到的？
- 完整面经：[快手后端开发校招面经](https://mianjingku.com/mianjing/kuaishou-houduan-campus)

## 后端开发（实习）

- 收录：8 篇面经，99 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面（部分岗位）
- 常考方向：Java 与并发、MySQL 与 Redis、消息队列、Agent 与 RAG、场景设计、手撕算法
- 示例题：
  - 核心线程 7、最大线程 20、队列容量 50，同时来 100 个请求，核心线程、非核心线程和队列按什么顺序被使用？
  - 多个 Agent 之间怎么传递上下文和上一步的执行结果？
- 完整面经：[快手后端开发实习面经](https://mianjingku.com/mianjing/kuaishou-houduan-intern)

## 前端开发（校招）

- 收录：8 篇面经，114 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 项目面 → HR 面
- 常考方向：JS 基础、Vue / React 原理、浏览器与网络、性能优化、手写代码、项目与 AI 应用
- 示例题：
  - 用户反馈网页加载很慢，可能是哪些方面的问题？怎么优化？
  - 手写：retry 函数，参数为要执行的函数、最大重试次数和重试间隔。
- 完整面经：[快手前端开发校招面经](https://mianjingku.com/mianjing/kuaishou-qianduan-campus)

## 算法工程师（校招）

- 收录：7 篇面经，85 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面 / 主管面（部分岗位） → HR 面
- 常考方向：项目深挖、召回与排序、生成式推荐、机器学习基础、评估指标、手撕算法
- 示例题：
  - 向量召回和策略召回各有什么优缺点？向量召回的性能问题怎么解决？
  - pointwise、pairwise、listwise 三种排序方式有什么区别、适用于什么场景？各自常用什么损失函数？
- 完整面经：[快手算法工程师校招面经](https://mianjingku.com/mianjing/kuaishou-suanfa-campus)

## 运营（校招）

- 收录：7 篇面经，84 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 / 交叉面 → 三面 · HR 面或主管面
- 常考方向：实习深挖、平台对比、活动策划、创作者运营、数据与指标、求职动机
- 示例题：
  - 如果快手想打入一线城市的年轻用户，该怎么做？
  - 如果你负责的商家 GMV 很低，可以从哪些方面解决？
- 完整面经：[快手运营校招面经](https://mianjingku.com/mianjing/kuaishou-yunying-campus)
