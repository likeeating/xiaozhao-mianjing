# 安永面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的安永近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 安永](https://mianjingku.com/gongsi/ey)。

## 审计校招面经

- 收录：7 篇面经，68 道题
- 面试轮次：网申 + 在线测评 → 群面（英文案例） → 经理面 / EIC 面 → 合伙人面（PIC，常与经理面合并）
- 常考方向：群面 / 英文案例、3 why、实习深挖、行为面、考证与专业、职业规划
- 示例题：
  - 如果你提出的创新建议没被同事采纳，甚至不支持你这样做，你会怎么办？
  - 灵活性和规范性哪个更重要？
- 完整面经：[安永审计校招面经](https://mianjingku.com/mianjing/ey-shenji-campus)

## 咨询（科技 / 可持续发展 / 战略咨询）校招面经

- 收录：3 篇面经，20 道题
- 面试轮次：网申 + 在线测评 → 群面（案例讨论 + 英文汇报，部分业务线当天接经理单面） → 经理面（部分业务线单独约面，约 20 分钟） → 合伙人面（约 30 分钟）
- 常考方向：群面 / 方案对比、英文汇报、求职动机、实习深挖、业务线认知、AI 与咨询
- 示例题：
  - 在 AI 这么发达的时代，你怎么看自己作为初级顾问的价值？
  - 案例：一家车企想推出 AI agent 产品，该不该做？
- 完整面经：[安永咨询（科技 / 可持续发展 / 战略咨询）校招面经](https://mianjingku.com/mianjing/ey-zixun-campus)
