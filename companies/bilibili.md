# 哔哩哔哩面经汇总：2 个岗位的面试题

按岗位整理的哔哩哔哩近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 哔哩哔哩](https://mianjingku.com/gongsi/bilibili)。

## 后端开发（校招）

- 收录：6 篇面经，60 道题
- 面试轮次：一面 · 技术面（实习 + 八股 + 手撕） → 二面 · 技术面（实习深挖 + 系统设计） → 三面 · 技术面或主管面
- 常考方向：实习深挖、MySQL 锁与日志、消息队列、Go 与并发、系统设计、手撕算法
- 示例题：
  - 两个事务同时对同一行执行 select for update，会发生什么？
  - 设计一个基于微服务的医患问诊系统，模块怎么划分？
- 完整面经：[哔哩哔哩后端开发校招面经](https://mianjingku.com/mianjing/bilibili-houduan-campus)

## 运营（校招）

- 收录：4 篇面经，45 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面或部门负责人面 → 三面 · 业务面（部分岗位） → HR 面
- 常考方向：实习深挖、B 站使用与理解、内容与会员运营、用户洞察、求职动机
- 示例题：
  - 你觉得用户增长和产品运营有什么区别？
  - B 站短视频和小红书短视频有什么不同？
- 完整面经：[哔哩哔哩运营校招面经](https://mianjingku.com/mianjing/bilibili-yunying-campus)
