# 中核集团面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的中核集团近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中核集团](https://mianjingku.com/gongsi/cnnc)。

## 机械 / 材料类技术岗校招面经

- 收录：3 篇面经，19 道题
- 面试轮次：测评 → 线下群面 / 单面 → 专业面（研究所） → 体检
- 常考方向：课题深挖、力学与材料、成绩与个人情况、倒班意向、求职动机
- 示例题：
  - 讲讲材料的氢脆现象，以及氢元素的检测方法和原理。
  - 有没有亲属在中核集团工作？
- 完整面经：[中核集团机械 / 材料类技术岗校招面经](https://mianjingku.com/mianjing/cnnc-jixie-campus)

## 软件开发校招面经

- 收录：3 篇面经，18 道题
- 面试轮次：线下一面 / 群面（单轮为主） → 体检
- 常考方向：Spring Boot、项目经历、性能与并发、场景题、出差意向
- 示例题：
  - 场景题：两个微服务，A 负责接收并解析文件，B 负责入库，每天下午两三点特别卡，可能是什么原因？怎么解决？
  - Spring Boot 怎么配置多数据源？
- 完整面经：[中核集团软件开发校招面经](https://mianjingku.com/mianjing/cnnc-ruanjian-kaifa-campus)

## 电气 / 自动化（核电统招岗）校招面经

- 收录：2 篇面经，29 道题
- 面试轮次：心理测评 / 行测 → 一面 · 群体自我介绍（按模板） → 二面 · 专业面 + 综合面 → 体检
- 常考方向：电力系统基础、自动控制原理、模电数电、成绩与排名、电站与调剂
- 示例题：
  - 继电保护的“四性”指什么？
  - 开环控制和闭环控制的定义和特点是什么？
- 完整面经：[中核集团电气 / 自动化（核电统招岗）校招面经](https://mianjingku.com/mianjing/cnnc-dianqi-campus)
