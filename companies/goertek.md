# 歌尔股份面经汇总：2 个岗位的面试题

按岗位整理的歌尔股份近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 歌尔股份](https://mianjingku.com/gongsi/goertek)。

## 结构研发 / 机械工程师（校招）

- 收录：7 篇面经，53 道题
- 面试轮次：一面 · 技术面 → 二面 · 主管 / 技术面
- 常考方向：项目深挖、公差与尺寸链、选型与校核、力学基础、综合素质、英文表达
- 示例题：
  - 挑一个你觉得最复杂的尺寸链讲讲：公差带怎么给，为什么这么给？
  - 项目里的电机怎么校核？对哪些参数校核？
- 完整面经：[歌尔股份结构研发 / 机械工程师校招面经](https://mianjingku.com/mianjing/goertek-jixie-campus)

## 硬件开发（校招）

- 收录：6 篇面经，37 道题
- 面试轮次：HR 电话面 → 一面 · 技术面 → 英语口语 / 主管面（部分岗位）
- 常考方向：项目深挖、电源设计、ADC 与采样、PCB 设计、英语口语、求职意向
- 示例题：
  - LDO 和 DC-DC 有什么区别？
  - 测过 ADC 参考电压的纹波吗？
- 完整面经：[歌尔股份硬件开发校招面经](https://mianjingku.com/mianjing/goertek-yingjian-campus)
