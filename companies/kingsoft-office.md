# 金山办公面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的金山办公近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 金山办公](https://mianjingku.com/gongsi/kingsoft-office)。

## 服务端开发校招面经

- 收录：7 篇面经，110 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：计算机网络、MySQL、Redis、Java / C++ 基础、场景设计、中间件
- 示例题：
  - 如果一定要用 UDP，怎么把它改造成可靠传输？需要考虑哪些问题？
  - 有两个 1GB 的大文件，怎么快速判断它们是否一致？
- 完整面经：[金山办公服务端开发校招面经](https://mianjingku.com/mianjing/kingsoft-office-houduan-campus)

## 前端开发校招面经

- 收录：7 篇面经，104 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：JS 基础、CSS 布局、浏览器与网络、Vue / React 原理、工程化与性能、项目深挖
- 示例题：
  - 如何往页面里一次性插入 1000 个 div？有哪些优化办法？
  - 强缓存和协商缓存分别怎么工作？index.html 适不适合做强缓存，为什么？
- 完整面经：[金山办公前端开发校招面经](https://mianjingku.com/mianjing/kingsoft-office-qianduan-campus)

## 软件测试校招面经

- 收录：4 篇面经，37 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 沟通
- 常考方向：测试用例设计、测试理论、自动化测试、Python 基础、项目深挖、求职动机
- 示例题：
  - 给 WPS 的“Word 转 PDF”功能设计测试用例。
  - 针对微信消息的收发设计测试用例。
- 完整面经：[金山办公软件测试校招面经](https://mianjingku.com/mianjing/kingsoft-office-ceshi-kaifa-campus)
