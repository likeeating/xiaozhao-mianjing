# 中国银行面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的中国银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中国银行](https://mianjingku.com/gongsi/boc)。

## 金融科技岗（软件中心 / 分行信息科技岗）校招面经

- 收录：7 篇面经，46 道题
- 面试轮次：笔试（含信息科技部分） → 软件中心：线下单面（开放题 + 简历） → 分行：群面（辩论 / 排序题 / 即兴演讲）+ 单面 → 体检与签约
- 常考方向：开放题、行为题、简历追问、即兴演讲、轮岗意愿、Java 与 SQL 基础
- 示例题：
  - 开放题：说说你理解的数字化银行。
  - 你觉得自己是原则型的人，还是灵活型的人？
- 完整面经：[中国银行金融科技岗（软件中心 / 分行信息科技岗）校招面经](https://mianjingku.com/mianjing/boc-jinrong-keji-campus)

## 营业网点业务岗 / 综合服务岗（分行校招）校招面经

- 收录：4 篇面经，33 道题
- 面试轮次：提前面（部分分行，笔试前线上面试） → 笔试 → 无领导小组讨论 → 半结构化面试（多对一，约 5–10 分钟） → 体检与签约
- 常考方向：无领导小组讨论、半结构化面试、柜员与轮岗、行为题、求职动机
- 示例题：
  - 你认为柜员是一个怎样的岗位？
  - 举一个团队合作中出现分歧的例子，你是怎么处理的？
- 完整面经：[中国银行营业网点业务岗 / 综合服务岗（分行校招）校招面经](https://mianjingku.com/mianjing/boc-zonghe-campus)
