# 商汤科技面经汇总：2 个岗位的面试题

按岗位整理的商汤科技近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 商汤科技](https://mianjingku.com/gongsi/sensetime)。

## 大模型 / 多模态算法实习（实习）

- 收录：6 篇面经，56 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 / 主管面 → HR 面（部分团队）
- 常考方向：项目深挖、大模型基础、强化学习对齐、多模态、Agent 设计、手撕代码
- 示例题：
  - GRPO 的奖励是怎么设计的？
  - 所有模型都超时或故障时怎么兜底？什么时候用规则引擎、什么时候转人工？服务恢复后怎么切回？
- 完整面经：[商汤科技大模型 / 多模态算法实习实习面经](https://mianjingku.com/mianjing/sensetime-suanfa-intern)

## 算法工程师（大模型 / 多模态）（校招）

- 收录：5 篇面经，42 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 / HR 面
- 常考方向：项目深挖、大模型基础、微调与训练、RAG、生成模型、手撕代码
- 示例题：
  - 为什么用 RoPE 而不是绝对位置编码？RoPE 能表示绝对位置信息吗？
  - 训练中 loss 曲线突然上升一定是坏事吗？怎么区分是参数设置有问题，还是模型在学新东西？
- 完整面经：[商汤科技算法工程师（大模型 / 多模态）校招面经](https://mianjingku.com/mianjing/sensetime-suanfa-campus)
