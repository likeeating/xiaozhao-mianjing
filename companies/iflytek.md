# 科大讯飞面经汇总：3 个岗位的面试题

按岗位整理的科大讯飞近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 科大讯飞](https://mianjingku.com/gongsi/iflytek)。

## 产品经理（校招）

- 收录：8 篇面经，80 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → HR 面
- 常考方向：简历深挖、用户调研、AI 与大模型、产品设计、求职动机
- 示例题：
  - 大模型有幻觉，模型准确率 90% 而用户期待 100%，中间这 10% 怎么补？
  - 市场调研和用户调研具体怎么做？最后得出了什么结论？
- 完整面经：[科大讯飞产品经理校招面经](https://mianjingku.com/mianjing/iflytek-chanpin-jingli-campus)

## 后端开发（Java / Agent）（校招）

- 收录：8 篇面经，104 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 / 项目面 → 三面 · HR 面 → 四面 · 高管面（部分岗位）
- 常考方向：项目深挖、Agent 与 RAG、AI Coding、MySQL、Java 并发、行为面
- 示例题：
  - Agent 进程重启后从哪里恢复？怎么避免重复执行有副作用的工具？
  - MySQL 什么时候会发生死锁？怎么解决？
- 完整面经：[科大讯飞后端开发（Java / Agent）校招面经](https://mianjingku.com/mianjing/iflytek-houduan-campus)

## 嵌入式软件开发（校招）

- 收录：8 篇面经，75 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · HR 面
- 常考方向：C/C++ 基础、内存管理、通信协议、RTOS、Linux 驱动、项目深挖
- 示例题：
  - RTOS 和 Linux 最大的区别是什么？RTOS 的任务是怎么调度的？
  - I2C 指定地址读的时序是怎样的？
- 完整面经：[科大讯飞嵌入式软件开发校招面经](https://mianjingku.com/mianjing/iflytek-qianrushi-campus)
