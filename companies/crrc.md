# 中国中车面经汇总：2 个岗位的面试题

按岗位整理的中国中车近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中国中车](https://mianjingku.com/gongsi/crrc)。

## 机械工程师（校招）

- 收录：8 篇面经，51 道题
- 面试轮次：宣讲会 + 现场笔试 / 测评 → 一面 · 群面（个人情况） → 二面 · 专业面（项目深挖） → 签约 / 谈薪
- 常考方向：个人与家庭情况、项目深挖、专业基础、工作意向、出差与倒班
- 示例题：
  - 家里是什么情况？父母做什么工作？是不是独生子女？有没有对象，对方在哪里读书或工作？
  - 能不能接受出国、出差、下矿、倒班这类工作安排？一年大概能接受多少天？
- 完整面经：[中国中车机械工程师校招面经](https://mianjingku.com/mianjing/crrc-jixie-campus)

## 研发工程师（电机 / 硬件 / 信号）（校招）

- 收录：3 篇面经，16 道题
- 面试轮次：一面 · 群面或单面 → 二面 · 项目 / 专业面 → 签约
- 常考方向：项目深挖、仿真与工具、硬件基础、工作意向、求职动机
- 示例题：
  - PCB 布线时要注意哪些问题？
  - 这个岗位偏软硬结合，你之前主要做软件，能接受吗？
- 完整面经：[中国中车研发工程师（电机 / 硬件 / 信号）校招面经](https://mianjingku.com/mianjing/crrc-yanfa-campus)
