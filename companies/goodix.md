# 汇顶科技面经汇总：2 个岗位的面试题

按岗位整理的汇顶科技近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 汇顶科技](https://mianjingku.com/gongsi/goodix)。

## 数字 IC 设计 / 验证（校招）

- 收录：6 篇面经，64 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面
- 常考方向：项目深挖、SV / UVM、寄存器模型、跨时钟域、AMBA 总线、手写 RTL
- 示例题：
  - 异步 FIFO 里用格雷码跨时钟域有什么限制和风险？
  - 怎么约束一个数组或队列里的元素各不相同？
- 完整面经：[汇顶科技数字 IC 设计 / 验证校招面经](https://mianjingku.com/mianjing/goodix-xinpian-campus)

## 嵌入式软件（校招）

- 收录：4 篇面经，37 道题
- 面试轮次：一面 · 技术面 → 二面 · 主管面
- 常考方向：项目深挖、笔试复盘、操作系统基础、MCU 与 RTOS、硬件基础、AI 使用
- 示例题：
  - MCU 没有操作系统时，怎么实现任务调度？
  - SPI 的四种工作模式是什么？
- 完整面经：[汇顶科技嵌入式软件校招面经](https://mianjingku.com/mianjing/goodix-qianrushi-campus)
