# 交通银行面经汇总：2 个岗位的面试题

按岗位整理的交通银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 交通银行](https://mianjingku.com/gongsi/bocom)。

## 金融科技岗（软件开发中心）（校招）

- 收录：8 篇面经，65 道题
- 面试轮次：AI 面试（部分批次） → 手撕代码 + 技术面（多数只有一轮） → 心理测评 → 背调与体检
- 常考方向：手撕代码、Java 八股、数据库与缓存、项目经历、Linux 与 Git、AI 面试
- 示例题：
  - 链表中每 k 个节点一组进行反转。
  - 缓存穿透、缓存击穿、缓存雪崩分别是什么？怎么应对？
- 完整面经：[交通银行金融科技岗（软件开发中心）校招面经](https://mianjingku.com/mianjing/bocom-jinrong-keji-campus)

## 分行储备生 / 客户经理（分行校招）（校招）

- 收录：3 篇面经，24 道题
- 面试轮次：笔试（部分批次） → 初面 · 无领导小组讨论或简短单面 → 终面 · 单面（约 10 分钟）
- 常考方向：无领导小组讨论、结构化单面、个人背景、工作意愿、客户经理
- 示例题：
  - 你之前的实习偏研究，之后做客户经理合适吗？
  - 一年柜员之后，你更想做对公还是对私？
- 完整面经：[交通银行分行储备生 / 客户经理（分行校招）校招面经](https://mianjingku.com/mianjing/bocom-zonghe-campus)
