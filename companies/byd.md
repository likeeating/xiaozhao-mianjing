# 比亚迪面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的比亚迪近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 比亚迪](https://mianjingku.com/gongsi/byd)。

## 研发工程师校招面经

- 收录：8 篇面经，79 道题
- 面试轮次：HR 面（综合面） → 专业面（用人部门） → 加面（部分人，跨部门匹配时）
- 常考方向：项目与课题深挖、岗位与城市意向、新能源行业认知、专业基础、HR 常规题
- 示例题：
  - 用 PPT 讲一讲你最相关的项目：你负责什么、遇到什么问题、怎么解决、最后效果如何。
  - 工作地点在深圳，能接受吗？
- 完整面经：[比亚迪研发工程师校招面经](https://mianjingku.com/mianjing/byd-yanfa-campus)

## 软件开发校招面经

- 收录：7 篇面经，58 道题
- 面试轮次：HR 面（综合面） → 技术面（用人部门）
- 常考方向：语言基础、数据库与框架、操作系统与网络、岗位匹配、HR 常规题
- 示例题：
  - 重写和重载有什么区别？
  - 意向岗位和意向城市是哪里？
- 完整面经：[比亚迪软件开发校招面经](https://mianjingku.com/mianjing/byd-ruanjian-kaifa-campus)
