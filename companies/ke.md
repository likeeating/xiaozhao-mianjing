# 贝壳面经汇总：2 个岗位的面试题

按岗位整理的贝壳近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 贝壳](https://mianjingku.com/gongsi/ke)。

## 产品经理（校招）

- 收录：8 篇面经，70 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 / 总监面 → HR 面
- 常考方向：实习深挖、指标与数据、产品认知、沟通协作、求职动机
- 示例题：
  - 播放时长下降，可能是内容质量低，也可能是推给了不感兴趣的用户，怎么定位？
  - 项目初期没有数据基础和基建，该怎么处理？
- 完整面经：[贝壳产品经理校招面经](https://mianjingku.com/mianjing/ke-chanpin-jingli-campus)

## 后端开发（校招）

- 收录：8 篇面经，82 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面（项目 + 场景） → HR 面
- 常考方向：项目深挖、Java 并发、MySQL 与 Redis、消息队列、场景设计、手写算法
- 示例题：
  - 分布式锁怎么实现可重入？
  - 场景题：同一个 IP 每分钟请求超过 120 次就拉黑，设计限流算法。
- 完整面经：[贝壳后端开发校招面经](https://mianjingku.com/mianjing/ke-houduan-campus)
