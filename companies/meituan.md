# 美团面经汇总：10 个岗位的面试题

按岗位整理的美团近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 美团](https://mianjingku.com/gongsi/meituan)。

## 测试开发（校招）

- 收录：8 篇面经，118 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术 / 主管面 → HR 面
- 常考方向：实习深挖、测试用例设计、自动化框架、业务场景题、AI 在测试中的应用、手撕代码
- 示例题：
  - 商场里有 3 部电梯，怎么设计测试用例？
  - 上线当天发现核心接口错误率飙升，但没有报错日志，你怎么定位？第一时间看什么？
- 完整面经：[美团测试开发校招面经](https://mianjingku.com/mianjing/meituan-ceshi-kaifa-campus)

## 后端开发（校招）

- 收录：8 篇面经，133 道题
- 面试轮次：一面 · 技术面（项目 + 基础 + 手撕或 AI Coding） → 二面 · 技术面（项目真实性 + 基础 + 现场编码）
- 常考方向：项目深挖、Java 与 JVM、MySQL 与 Redis、计算机网络、AI Coding、手撕算法
- 示例题：
  - 什么是缓存雪崩？有哪些处理方法？
  - 手写：反转链表的指定区间。
- 完整面经：[美团后端开发校招面经](https://mianjingku.com/mianjing/meituan-houduan-campus)

## 后端开发（实习）

- 收录：8 篇面经，105 道题
- 面试轮次：笔试 / AI 面（部分） → 一面 · 技术面 → 二面 · 主管面
- 常考方向：项目拷打、Java 并发与 JVM、Spring、MySQL 与索引、Redis 与缓存、手撕算法
- 示例题：
  - 线程池核心线程 2、最大线程 4、队列容量 10，任务不断进来时线程是怎么创建和分配的？
  - 消息队列有多个分区，但业务要求顺序消费，怎么保证？
- 完整面经：[美团后端开发实习面经](https://mianjingku.com/mianjing/meituan-houduan-intern)

## 后端开发（Java）（社招）

- 收录：8 篇面经，79 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面（部分岗位） → HR 面
- 常考方向：项目深挖、Java 并发与 JVM、Spring 与 MyBatis、MySQL 与 Redis、业务场景设计、算法题
- 示例题：
  - 场景题：发一批优惠券，库存 1000 张，很多用户来领，每人每天限领两张，怎么设计？
  - 4G 内存、8G 的数据文件，怎么统计出现频率最高的前 10 个词？
- 完整面经：[美团后端开发（Java）社招面经](https://mianjingku.com/mianjing/meituan-houduan-social)

## 前端开发（校招）

- 收录：8 篇面经，117 道题
- 面试轮次：笔试 → 一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面（部分） → HR 面
- 常考方向：实习深挖、浏览器与存储、网络与跨域、JS 基础与事件循环、Vue / React、手撕
- 示例题：
  - 同时打开两个同域名的标签页，在标签 1 里修改 sessionStorage，会同步到标签 2 吗？
  - 实现一个类似 Ctrl+F 的页面搜索功能，怎么做？
- 完整面经：[美团前端开发校招面经](https://mianjingku.com/mianjing/meituan-qianduan-campus)

## 算法工程师（校招）

- 收录：8 篇面经，92 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面（部分岗位） → HR 面
- 常考方向：项目与实习深挖、大模型训练与微调、强化学习对齐、搜索推荐、Transformer 原理、手撕代码
- 示例题：

  - 用户行为序列建模时，怎么把时间和空间信息融进去？
- 完整面经：[美团算法工程师校招面经](https://mianjingku.com/mianjing/meituan-suanfa-campus)

## 产品经理（校招）

- 收录：7 篇面经，58 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面（常为上级主管） → HR 面
- 常考方向：简历深挖、数据指标、业务场景题、AI 产品、求职动机
- 示例题：
  - 竞品调研和用户调研是怎么做的？
  - 如果要在一个新城市上线共享单车，你会怎么冷启动？
- 完整面经：[美团产品经理校招面经](https://mianjingku.com/mianjing/meituan-chanpin-jingli-campus)

## 数据分析（校招）

- 收录：7 篇面经，67 道题
- 面试轮次：一面 · 业务面（团队成员） → 二面 · 业务面（直属主管） → 三面 · 交叉面（部分团队） → HR 面
- 常考方向：简历深挖、指标异动分析、业务 case、估算题、SQL、机器学习
- 示例题：
  - 实习写周报时看哪些指标？哪些数据要自己取，哪些需要和别人协作？
  - 长视频平台可以怎样提高收益？
- 完整面经：[美团数据分析校招面经](https://mianjingku.com/mianjing/meituan-shuju-fenxi-campus)

## 运营（校招）

- 收录：7 篇面经，70 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → 三面 · 主管面（部分岗位另有加面） → HR 面
- 常考方向：实习深挖、运营思维、业务 case、竞品分析、求职动机

## 产品经理（实习）

- 收录：4 篇面经，35 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面或 AI coding 面 → HR 沟通
- 常考方向：实习深挖、指标与数据、产品认知、美团产品体验、情景题
- 示例题：
  - 常用美团的哪些产品？有哪些不爽的地方？你会怎么优化？
  - 产品迭代是在什么用户场景下触发的？发现了什么问题、提了什么方案、最终效果如何？
- 完整面经：[美团产品经理实习面经](https://mianjingku.com/mianjing/meituan-chanpin-jingli-intern)
