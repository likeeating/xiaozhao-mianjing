# 工商银行面经汇总：2 个岗位的面试题

按岗位整理的工商银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 工商银行](https://mianjingku.com/gongsi/icbc)。

## 金融科技岗（软件开发中心 / 分行科技菁英）（校招）

- 收录：12 篇面经，83 道题
- 面试轮次：软开中心一面 · 专业面（提前批可先面后笔） → 统一笔试（行测 + 英语 + 信息科技） → 软开中心二面 · 综合面或无领导小组讨论 → 分行科技菁英 · 无领导 / 辩论 + 半结构化单面 → 体检与签约
- 常考方向：简历项目深挖、计算机基础、Java 与数据库、大模型、无领导小组讨论、求职动机
- 示例题：
  - 在 Linux 服务器上怎么查看各进程占用的内存，并找出占用最多的前十个？JVM 有哪些内存排查和调优工具？
  - 辩论题：处理客户投诉，应该重在用情还是重在用理？辩论结束后组间合作，提出 3 条应对客户投诉的措施。
- 完整面经：[工商银行金融科技岗（软件开发中心 / 分行科技菁英）校招面经](https://mianjingku.com/mianjing/icbc-jinrong-keji-campus)

## 客户经理 / 综合营销岗（分行校招）（校招）

- 收录：5 篇面经，35 道题
- 面试轮次：笔试（线下，行测 + 企业文化） → 无领导小组讨论 / 对抗式辩论（排序、方案设计、辩论等） → 半结构化面试（部分分行先答题本固定题，再结合简历追问） → 心理测评（部分分行）
- 常考方向：无领导小组讨论、对抗式辩论、求职动机、岗位认知、压力追问、客户服务情景
- 示例题：
  - 你学的专业和银行不对口，为什么还想报考银行？
  - “懒人经济”兴起，你支持还是反对？先独立陈述观点，再按考官指定的分组讨论，由代表总结本组理由。
- 完整面经：[工商银行客户经理 / 综合营销岗（分行校招）校招面经](https://mianjingku.com/mianjing/icbc-zonghe-campus)
