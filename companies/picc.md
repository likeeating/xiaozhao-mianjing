# 中国人保面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的中国人保近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中国人保](https://mianjingku.com/gongsi/picc)。

## 信息科技岗（人保科技 / 财险寿险科技岗）校招面经

- 收录：8 篇面经，54 道题
- 面试轮次：笔试（行测 + 专业） → 一面 · 材料题 + 结构化 + 技术基础 → 二面 · 项目面 / 综合面 → 终面（部分岗位）
- 常考方向：材料题、结构化面试、技术基础、项目经历、调剂与意向、需求分析
- 示例题：
  - 读完这段材料，你觉得未来对人保影响最大的是什么？
  - MySQL 索引在什么情况下会失效？
- 完整面经：[中国人保信息科技岗（人保科技 / 财险寿险科技岗）校招面经](https://mianjingku.com/mianjing/picc-jinrong-keji-campus)

## 综合岗（省市分公司 / 人保健康）校招面经

- 收录：3 篇面经，20 道题
- 面试轮次：笔试（行测 + 经济金融） → 一面 · 省公司单面 → 二面 · 市公司 / 部门面 → 三面（部分子公司）
- 常考方向：求职动机、公司了解、基层轮岗、岗位与地域调剂、简历经历
- 示例题：
  - 需要到基层轮岗，你能接受吗？
  - 省公司名额少，是否考虑业务类岗位或地级市分公司？
- 完整面经：[中国人保综合岗（省市分公司 / 人保健康）校招面经](https://mianjingku.com/mianjing/picc-zonghe-campus)

## 信息科技实习生（开发 / 大数据）实习面经

- 收录：2 篇面经，17 道题
- 面试轮次：一面 · 线上技术面
- 常考方向：SQL 与索引、大数据组件、数仓、项目难点、研究方向
- 示例题：

  - 有没有用过索引？一般怎么用？
