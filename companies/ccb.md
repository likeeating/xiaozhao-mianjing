# 建设银行面经汇总：2 个岗位的面试题

按岗位整理的建设银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 建设银行](https://mianjingku.com/gongsi/ccb)。

## 金融科技岗（分行科技岗 / 直属机构）（校招）

- 收录：5 篇面经，41 道题
- 面试轮次：笔试（行测 + 行史 + 英语，科技岗含专业题） → 无领导小组讨论（部分分行） → 半结构化面试（部分分行连续两轮单面） → 直属机构：技术面 + 综合面 → 体检与签约
- 常考方向：半结构化面试、无领导小组讨论、稳定性考察、Java 基础、轮岗意愿
- 示例题：
  - 假如你刚入职，老员工都很忙、没空带你，面对不熟悉的业务你会怎么做？
  - 分布式 Session 怎么实现？
- 完整面经：[建设银行金融科技岗（分行科技岗 / 直属机构）校招面经](https://mianjingku.com/mianjing/ccb-jinrong-keji-campus)

## 综合岗 / 柜员（分行校招）（校招）

- 收录：5 篇面经，32 道题
- 面试轮次：笔试 → 无领导小组讨论 / 对抗辩论 → 半结构化面试（全组轮答、抽题作答或多对一单面） → 体检与签约
- 常考方向：无领导小组讨论、半结构化面试、稳定性考察、营销演示、客户服务、岗位认知
- 示例题：
  - 现场示范：你会怎么向顾客推销一款理财产品？
  - 如果最后没有收到 offer，你觉得会是什么原因？
- 完整面经：[建设银行综合岗 / 柜员（分行校招）校招面经](https://mianjingku.com/mianjing/ccb-zonghe-campus)
