# 京东面经汇总：5 个岗位的面试题

按岗位整理的京东近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 京东](https://mianjingku.com/gongsi/jd)。

## 后端开发（校招）

- 收录：9 篇面经，105 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面（部分批次排在最前）
- 常考方向：Java 与 Spring、JVM、MySQL 与 Redis、消息队列、高并发项目、求职动机
- 示例题：
  - 缓存穿透是什么？有哪些解决方案？
  - MySQL 的间隙锁是什么？
- 完整面经：[京东后端开发校招面经](https://mianjingku.com/mianjing/jd-houduan-campus)

## 采销管培生（校招）

- 收录：8 篇面经，94 道题
- 面试轮次：群面（部分专场或批次） → 一面 · 业务面 → 二面 · 业务面（部门负责人） → HR 面（部分为线下）
- 常考方向：采销理解、业务情景题、经历深挖、求职动机、行为面试、抗压与 HR 面
- 示例题：
  - 你认为电商运营的核心数据维度有哪些？
  - 你对京东采销的理解是什么？和传统采销有什么区别？
- 完整面经：[京东采销管培生校招面经](https://mianjingku.com/mianjing/jd-guanpeisheng-campus)

## 后端开发（实习）

- 收录：8 篇面经，101 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面或 HR 面
- 常考方向：项目深挖、Redis 与分布式锁、MySQL 与事务、Java 基础与并发、AI 工具使用、综合面
- 示例题：
  - 下单后超过十分钟没支付，系统要自动关闭订单，你会用什么技术实现？
  - 什么场景下企业会把事务隔离级别从可重复读降到读已提交？
- 完整面经：[京东后端开发实习面经](https://mianjingku.com/mianjing/jd-houduan-intern)

## 算法工程师（校招）

- 收录：8 篇面经，84 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：项目深挖、大模型微调与对齐、多模态与扩散模型、推荐模型、Transformer 细节、手撕代码
- 示例题：
  - 为什么用 GRPO 而不用 DPO？什么样的任务更适合 DPO？
  - DIN 的原理是什么？有什么优势？
- 完整面经：[京东算法工程师校招面经](https://mianjingku.com/mianjing/jd-suanfa-campus)

## 产品经理（校招）

- 收录：6 篇面经，72 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → HR 面
- 常考方向：简历深挖、数据与指标、行业与竞争分析、AI 产品、B 端产品、求职动机
- 示例题：
  - 你在实习中是怎么做竞品分析的？
  - 广告侧和用户侧的策略发生冲突时，你会怎么解决？
- 完整面经：[京东产品经理校招面经](https://mianjingku.com/mianjing/jd-chanpin-jingli-campus)
