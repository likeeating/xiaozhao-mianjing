# 农业银行面经汇总：2 个岗位的面试题

按岗位整理的农业银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 农业银行](https://mianjingku.com/gongsi/abc)。

## 金融科技岗（研发中心 / 分行信息科技岗）（校招）

- 收录：4 篇面经，29 道题
- 面试轮次：线下笔试 → 现场机试 · 两道编程题（研发中心） → 技术面 · 多对多群面 → 综合面 · 无领导小组讨论 → 分行信息科技岗：群面 + 单面 → 体检与签约
- 常考方向：编程机试、技术群面、接口设计、Java 与数据库、无领导小组讨论、稳定性考察
- 示例题：
  - 8 分钟设计题：实现一个客户校验接口，普通客户要检查身份证是否到期、是否开有必要账户，军人客户要检查军官证是否到期，写出伪代码。
  - 微服务之间如何通信？微服务的容灾怎么做？
- 完整面经：[农业银行金融科技岗（研发中心 / 分行信息科技岗）校招面经](https://mianjingku.com/mianjing/abc-jinrong-keji-campus)

## 综合业务岗 / 柜员（分行校招）（校招）

- 收录：4 篇面经，28 道题
- 面试轮次：笔试（行测 + 综合知识 + 英语） → 开场情景题（部分分行） → 半结构化面试（多对一） → 体检与签约
- 常考方向：半结构化面试、情景题、求职动机、基层与轮岗、个人情况
- 示例题：
  - 团队里有成员经常迟到早退、不愿干活，长期没有业绩，会给团队带来什么问题？该怎么解决？你作为其中一员能做些什么？
  - 轮岗做柜员，你能接受多少年？
- 完整面经：[农业银行综合业务岗 / 柜员（分行校招）校招面经](https://mianjingku.com/mianjing/abc-zonghe-campus)
