# 中信建投面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的中信建投近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中信建投](https://mianjingku.com/gongsi/csc)。

## 投行（股权承做等）实习面经

- 收录：5 篇面经，40 道题
- 面试轮次：初面 · 简历面（投行委或项目组） → 无领导辩论（部分项目组） → 后续面 · 项目组 / HR
- 常考方向：简历深挖、尽调与核查、IPO 实务、财务基础、求职动机
- 示例题：
  - 你做了哪些尽职调查工作？业务方面的尽调做过哪些？
  - 你怎么理解函证？
- 完整面经：[中信建投投行（股权承做等）实习面经](https://mianjingku.com/mianjing/csc-touhang-intern)

## 行业研究（研究所 / 投研实习）实习面经

- 收录：5 篇面经，34 道题
- 面试轮次：笔试 / 网测（部分岗位） → 一面 · 简历面（常多人同场） → 二面 · 分析师面
- 常考方向：简历深挖、研究动机、估值与报表、宏观与行业观点、实习安排
- 示例题：
  - 你有哪些适合做行研的特质？举例说明。
  - PE、PEG 和 PB 指标各自的适用场景和区别是什么？
- 完整面经：[中信建投行业研究（研究所 / 投研实习）实习面经](https://mianjingku.com/mianjing/csc-hangye-yanjiu-intern)

## 财富管理 / 理财规划师（营业部）校招面经

- 收录：2 篇面经，13 道题
- 面试轮次：一面 · 视频或线下单面 → 二面 · 线下面（部分营业部）
- 常考方向：求职动机、岗位认知、简历经历、行业看法、个人情况
- 示例题：
  - 你怎么理解理财规划师这个岗位？
  - 之前做的是财务和审计实习，为什么投财富管理岗？
- 完整面经：[中信建投财富管理 / 理财规划师（营业部）校招面经](https://mianjingku.com/mianjing/csc-zonghe-campus)
