# 招商证券面经汇总：2 个岗位的面试题

按岗位整理的招商证券近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 招商证券](https://mianjingku.com/gongsi/cmsc)。

## 财富顾问 / 财富管理岗（校招）

- 收录：3 篇面经，24 道题
- 面试轮次：笔试（行测 + 金融知识） → 一面 · 多人同场轮流问答 → 二面 · 小组面（部分场次）
- 常考方向：岗位认知、投资经历、求职动机、市场观点、工作地点与到岗
- 示例题：
  - 你手里有一只一直亏损的基金，会继续持有、卖掉还是换掉？为什么？
  - 如果客户问到你不熟悉的股票或理财产品，你会怎么做？
- 完整面经：[招商证券财富顾问 / 财富管理岗校招面经](https://mianjingku.com/mianjing/cmsc-zonghe-campus)

## 行业研究（研究所 / 资管）（实习）

- 收录：3 篇面经，25 道题
- 面试轮次：笔试 · 研究底稿（部分岗位） → 初面 · 简历面（可能多人同场）
- 常考方向：简历深挖、行业观点、研究框架、财务分析、求职动机
- 示例题：
  - 你分析一家公司的框架是什么？
  - 买方行研和卖方行研有什么区别？
- 完整面经：[招商证券行业研究（研究所 / 资管）实习面经](https://mianjingku.com/mianjing/cmsc-hangye-yanjiu-intern)
