# 腾讯面经汇总：14 个岗位的面试题

按岗位整理的腾讯近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 腾讯](https://mianjingku.com/gongsi/tencent)。

## 后台开发（实习）

- 收录：12 篇面经，116 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面（部分部门）
- 常考方向：手撕算法、语言基础、MySQL 与 Redis、操作系统、系统设计、Agent 与 RAG
- 示例题：
  - Redis 为什么快？从整体上看它是单线程的吗？
  - 项目引入缓存中间件后会带来什么问题？你是怎么处理的？数据不一致的窗口有多长，业务上能接受吗？
- 完整面经：[腾讯后台开发实习面经](https://mianjingku.com/mianjing/tencent-houduan-intern)

## 后台开发（校招）

- 收录：10 篇面经，100 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面 → 四面 · 总监面（部分部门） → HR 面
- 常考方向：手撕算法、操作系统、计算机网络、缓存与消息队列、系统设计、实习深挖
- 示例题：
  - TCP 四次挥手时 TIME_WAIT 阶段在做什么？要等多久？
  - Linux 上一个进程开了 100 个线程，结束这个进程时怎么保证所有线程都被终止？
- 完整面经：[腾讯后台开发校招面经](https://mianjingku.com/mianjing/tencent-houduan-campus)

## 产品经理（实习）

- 收录：8 篇面经，64 道题
- 面试轮次：初试 · 业务面 → 复试 · 业务面 → HR 面
- 常考方向：经历深挖、自家产品分析、产品设计、估算与情景题、AI 产品、个人经历与动机
- 示例题：
  - 微信搜索在使用链路上有哪些可以改进的地方？
  - 打开腾讯视频随便进一个推荐的剧集或频道，用 5 分钟后，从用户角度提改进建议。
- 完整面经：[腾讯产品经理实习面经](https://mianjingku.com/mianjing/tencent-chanpin-jingli-intern)

## 客户端开发（校招）

- 收录：8 篇面经，99 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面（部分团队） → HR 面
- 常考方向：实习深挖、Android / iOS 机制、C++ 底层、网络、游戏引擎与同步、手撕
- 示例题：
  - 页面请求还没返回用户就离开了，结果怎么保存和派发？
  - 帧同步和状态同步各有什么优缺点？FPS 游戏该用哪种？帧同步怎么保证各客户端一致？
- 完整面经：[腾讯客户端开发校招面经](https://mianjingku.com/mianjing/tencent-kehuduan-campus)

## 前端开发（校招）

## 算法工程师（校招）

- 收录：8 篇面经，98 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 / 面委会（部分岗位） → HR 面

## 测试开发（校招）

- 收录：7 篇面经，81 道题
- 面试轮次：一面 · 技术面 → 二面及以后 · 技术面 / HR 面（公开面经较少）

## 后台开发（社招）

- 收录：6 篇面经，86 道题
- 面试轮次：一面 · 技术面（常含限时编程） → 二面 · 技术面 → 三面 / GM 面 → 面委会（较高职级） → HR 面
- 常考方向：项目架构深挖、网络与操作系统、语言底层（C++ / Go）、中间件与云原生、场景设计题、编程题
- 示例题：

## 前端开发（实习）

- 收录：6 篇面经，106 道题

- 常考方向：项目深挖、网络与缓存、性能优化、流式对话与 AI、框架与工程化、手撕
