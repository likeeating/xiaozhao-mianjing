# 中国广核面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的中国广核近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中国广核](https://mianjingku.com/gongsi/cgn)。

## 机械类技术岗校招面经

- 收录：3 篇面经，30 道题
- 面试轮次：人才测评 + 心理测评 → 一面 · 无领导小组 / AI 面试 → 二面 · 专业面 → 三面 · HR 面 → 体检 + 岗位分配
- 常考方向：专业课程、项目与专利、安全与质量、工作地点与倒班、求职动机
- 示例题：
  - 是不是只接受研发岗？运维岗需要倒班、上夜班，愿意考虑吗？
  - 如果公司某个部件出现了安全问题，你觉得应该怎么解决？
- 完整面经：[中国广核机械类技术岗校招面经](https://mianjingku.com/mianjing/cgn-jixie-campus)

## 电气 / 自动化类技术岗校招面经

- 收录：2 篇面经，13 道题
- 面试轮次：测评 → 一面 · AI 面试 / 无领导小组 → 二面 · 专业面 → 三面 · HR 面 → 体检
- 常考方向：自动控制、模电与数电、项目经历、求职动机、个人情况
- 示例题：
  - PID 控制起什么作用？参数一般怎么调？
  - 什么是 PN 结？
- 完整面经：[中国广核电气 / 自动化类技术岗校招面经](https://mianjingku.com/mianjing/cgn-dianqi-campus)

## 计算机类（数字化 / 信息技术）校招面经

- 收录：2 篇面经，40 道题
- 面试轮次：测评 → 一面 · 无领导小组 → 二面 · 技术 / 综合面 → 三面 · HR 面 → 体检 + 岗位分配
- 常考方向：计算机基础、场景题、项目经历、求职动机、地点与调剂、运行岗
- 示例题：
  - 场景题：设计一个能根据人的体温自动调节温度的空调，需要用到哪些计算机知识？
  - 中广核大部分业务和你的专业关系不大，为什么还选择这里？
- 完整面经：[中国广核计算机类（数字化 / 信息技术）校招面经](https://mianjingku.com/mianjing/cgn-ruanjian-kaifa-campus)
