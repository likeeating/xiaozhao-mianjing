# 富途面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的富途近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 富途](https://mianjingku.com/gongsi/futu)。

## 前端开发校招面经

- 收录：8 篇面经，77 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · HR 面
- 常考方向：前端基础、工程化、网络与安全、场景编码、算法与逻辑题
- 示例题：
  - 共享屏幕：给一个汇率兑换页面和说明，十分钟内用代码表达出相关逻辑（越详细越好）。
  - 逻辑题：从蓝墨水取一滴滴入红墨水，再从混合后的红墨水取一滴滴回蓝墨水，哪边混入对方的更多？
- 完整面经：[富途前端开发校招面经](https://mianjingku.com/mianjing/futu-qianduan-campus)

## 后台开发校招面经

- 收录：5 篇面经，79 道题
- 面试轮次：一面 · 技术面（八股 + 手撕） → 二面 · 技术面 / 场景设计 → HR 面
- 常考方向：手写算法、网络与操作系统、MySQL 与 Redis、场景设计、智力题、C++ / Go 基础
- 示例题：
  - 怎么设计一个随机数生成器？（面试官会逐步加条件）
  - 智力题：三个箱子分别装苹果、梨和混合水果，标签全部贴错，只从一个箱子里摸一个水果，怎么把标签改对？
- 完整面经：[富途后台开发校招面经](https://mianjingku.com/mianjing/futu-houduan-campus)
