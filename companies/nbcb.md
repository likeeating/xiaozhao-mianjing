# 宁波银行面经汇总：3 个岗位的面试题

按岗位整理的宁波银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 宁波银行](https://mianjingku.com/gongsi/nbcb)。

## 金融科技岗（含总行金融科技定向生）（校招）

- 收录：8 篇面经，60 道题
- 面试轮次：笔试 → 一面 · 技术面（八股 + 手撕） → 二面 · HR / 行政面 → 终面 · 线下辩论或群面
- 常考方向：Java 基础、Spring、数据库与索引、手撕代码、求职动机、线下辩论
- 示例题：
  - 什么样的字段适合建索引？
  - 你家在外省，为什么选择来宁波银行？
- 完整面经：[宁波银行金融科技岗（含总行金融科技定向生）校招面经](https://mianjingku.com/mianjing/nbcb-jinrong-keji-campus)

## 管培生 / 分行培训生（校招）

- 收录：3 篇面经，21 道题
- 面试轮次：初面 · 视频或 2 对 1（5–10 分钟） → 笔试 / 测评 → 二面 · 抽题即兴演讲 → 终面 · 单面或无领导小组讨论
- 常考方向：即兴演讲、求职动机、家庭与地域、营销意愿、无领导小组讨论
- 示例题：
  - 如果让你跑营销，你愿意吗？不愿意的话为什么？
  - 为什么选择宁波银行？
- 完整面经：[宁波银行管培生 / 分行培训生校招面经](https://mianjingku.com/mianjing/nbcb-guanpeisheng-campus)

## 金融科技部暑期实习（开发 / 算法）（实习）

- 收录：3 篇面经，27 道题
- 面试轮次：笔试 + 测评 → 一面 · 技术面 → 二面 · HR 面
- 常考方向：Java 基础、项目深挖、手撕代码、大模型、求职动机
- 示例题：
  - 为什么会来宁波？
  - 过滤器、拦截器和 AOP 的执行顺序是怎样的？
- 完整面经：[宁波银行金融科技部暑期实习（开发 / 算法）实习面经](https://mianjingku.com/mianjing/nbcb-jinrong-keji-intern)
