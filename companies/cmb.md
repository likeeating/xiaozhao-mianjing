# 招商银行面经汇总：3 个岗位的面试题

按岗位整理的招商银行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 招商银行](https://mianjingku.com/gongsi/cmb)。

## 金融科技岗（招银网络科技 / 分行金融科技）（校招）

- 收录：8 篇面经，94 道题
- 面试轮次：笔试（行测 + 技术题） → 一面 · 技术面 → 二面 · 主管面 / 场景面（多为线下） → HR 面 → sp 加面（部分候选人）
- 常考方向：Java 基础、数据库与中间件、场景设计、手撕算法、项目深挖、HR 综合面
- 示例题：
  - 亿级用户的积分怎么做实时排名，让每个用户都能看到自己的名次？
  - 两个人对项目方案有分歧，时间只够做其中一个人的方案，你怎么办？
- 完整面经：[招商银行金融科技岗（招银网络科技 / 分行金融科技）校招面经](https://mianjingku.com/mianjing/cmb-jinrong-keji-campus)

## 分行 · 综合岗（校招）

- 收录：7 篇面经，57 道题
- 面试轮次：AI 面 → 群面 / 辩论 → 半结构化单面（终面）
- 常考方向：AI 面、群面 / 辩论、情景题、求职动机、城市与调剂、简历深挖
- 示例题：
  - 领导有明确规定，但客户坚持提出不合理要求，你会怎么处理？最好结合真实经历讲。
  - 你怎么看客户经理需要陌生拜访、电话营销这类工作？
- 完整面经：[招商银行分行 · 综合岗校招面经](https://mianjingku.com/mianjing/cmb-zonghe-campus)

## 管培生（含分行定向培养生）（校招）

- 收录：5 篇面经，45 道题
- 面试轮次：AI 面（部分年份为现场话题陈述） → 群面 / 辩论 → 单面 · 简历与行为面（2v1） → 终面 · 案例 PPT 答辩
- 常考方向：AI 面、群面 / 辩论、求职动机、简历深挖、案例分析 PPT、英文表达
- 示例题：
  - 后工业化时代，传统重工业城市应该怎样转型？
  - 你做过不少券商实习，为什么最后选择银行？
- 完整面经：[招商银行管培生（含分行定向培养生）校招面经](https://mianjingku.com/mianjing/cmb-guanpeisheng-campus)
