# 爱奇艺面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的爱奇艺近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 爱奇艺](https://mianjingku.com/gongsi/iqiyi)。

## 前端开发实习面经

- 收录：6 篇面经，111 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 / leader 面（部分） → 三面 · 技术面（少数）
- 常考方向：JS 基础、CSS 布局、Vue / React 原理、浏览器与网络、手写代码、实习安排
- 示例题：
  - setState 是同步还是异步？React 18 前后有什么区别？在 React 事件、定时器、原生事件里分别表现如何？
  - 鼠标移到一个元素上时，从它左下角弹出一个弹窗，怎么实现？
- 完整面经：[爱奇艺前端开发实习面经](https://mianjingku.com/mianjing/iqiyi-qianduan-intern)

## 产品经理（含后台、数据产品）实习面经

- 收录：5 篇面经，53 道题
- 面试轮次：一面 · 业务面 → 二面 · 主管面（部分）
- 常考方向：实习深挖、产品分析、数据与指标、沟通协作、求职动机
- 示例题：
  - 每个季度的重点剧播出时数据很好，完结后又跌回去。作为产品经理，你会怎么减少这类流失？
  - B 端和 C 端在用户需求、产品设计等方面有什么差异？
- 完整面经：[爱奇艺产品经理（含后台、数据产品）实习面经](https://mianjingku.com/mianjing/iqiyi-chanpin-jingli-intern)
