# 迈瑞医疗面经汇总：3 个岗位的面试题

按岗位整理的迈瑞医疗近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 迈瑞医疗](https://mianjingku.com/gongsi/mindray)。

## 机械开发工程师（结构设计）（校招）

- 收录：8 篇面经，56 道题
- 面试轮次：一面 · 技术面（线上） → 二面 · 主管 / HRBP 面（线上） → 三面 · 线下面
- 常考方向：项目深挖、机械设计基础、材料与热处理、仿真与选型、医疗器械认知、期望与意向
- 示例题：
  - 拿到项目需求时，核心结构设计主要考虑哪些点？
  - 你了解哪些医疗器械？
- 完整面经：[迈瑞医疗机械开发工程师（结构设计）校招面经](https://mianjingku.com/mianjing/mindray-jixie-campus)

## 软件开发（C++ 为主）（校招）

- 收录：8 篇面经，60 道题
- 面试轮次：一面 · 技术面（视频） → 二面 · 技术面 → 三面 · 线下面
- 常考方向：C++ 基础、多线程与同步、计算机网络、手撕代码、项目深挖、职业规划与 offer
- 示例题：
  - C++ 的多态是怎么实现的？虚函数的原理是什么？
  - 手撕：实现一个固定容量为 N 的环形队列，支持多个生产者和多个消费者并发访问。
- 完整面经：[迈瑞医疗软件开发（C++ 为主）校招面经](https://mianjingku.com/mianjing/mindray-ruanjian-kaifa-campus)

## 硬件工程师（模拟 / 电源 / 信号链）（校招）

- 收录：5 篇面经，53 道题
- 面试轮次：一面 · 技术面 → 二面 · 半技术半综合 → 三面 · 线下面
- 常考方向：项目设计思路、器件选型、电源设计、精度与误差分析、PCB 与高速信号、城市与 offer
- 示例题：
  - 电源引入的噪声和纹波会影响哪些模块？有什么表现？纹波是怎么考虑的？
  - 运放选型时要考虑哪些参数？
- 完整面经：[迈瑞医疗硬件工程师（模拟 / 电源 / 信号链）校招面经](https://mianjingku.com/mianjing/mindray-yingjian-campus)
