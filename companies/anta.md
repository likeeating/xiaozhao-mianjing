# 安踏面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的安踏近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 安踏](https://mianjingku.com/gongsi/anta)。

## 商品运营 / 商品管理（含斐乐）校招面经

- 收录：5 篇面经，48 道题
- 面试轮次：AI 面试（行为题） → 群面 · 无领导小组讨论 + 抢答 → HR 沟通 + 案例分析 PPT → 终面 · 案例汇报 + 多位领导提问
- 常考方向：行为面试、群面、案例分析、商品与库存、求职动机、个人情况
- 示例题：
  - 你怎么理解调拨？它在商品管理里起什么作用？
  - 在库存不变的情况下，怎么提升某个商品包（比如故事包）的流量和销量？
- 完整面经：[安踏商品运营 / 商品管理（含斐乐）校招面经](https://mianjingku.com/mianjing/anta-yunying-campus)

## 供应链（采购 / 物流）校招面经

- 收录：3 篇面经，25 道题
- 面试轮次：AI 面试（行为题） → 群面 · 无领导小组讨论 → 案例分析 + 面试 → 终面
- 常考方向：行为面试、群面、个人情况、求职动机、案例分析
- 示例题：
  - 你对安踏有什么认识？
  - 讲一次你处理突发事件的经历，当时是怎么应对的？
- 完整面经：[安踏供应链（采购 / 物流）校招面经](https://mianjingku.com/mianjing/anta-gongyinglian-campus)

## 零售管培生校招面经

- 收录：2 篇面经，10 道题
- 面试轮次：AI 测评（行为视频 + 性格 + 数据题） → 群面 · 无领导小组讨论 → HR 面（1 对 1） → 终面
- 常考方向：群面、门店经营、岗位理解、职业规划、行为面试
- 示例题：
  - 无领导小组讨论：某门店店员销售技能和服务意识不足，店长管理粗暴，陈列过时、爆品缺货，和竞品差异也不大。假如你是新任店长，怎么提升销量？
  - 你觉得当好一名店长需要学会哪些东西？
- 完整面经：[安踏零售管培生校招面经](https://mianjingku.com/mianjing/anta-guanpeisheng-campus)
