# TCL面经汇总：2 个岗位的面试题

## C++ / 安卓软件开发（校招）

- 收录：7 篇面经，59 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：C++ 基础、操作系统、场景题、安卓开发、项目深挖、求职意向
- 示例题：

- 完整面经：[TCLC++ / 安卓软件开发校招面经](https://mianjingku.com/mianjing/tcl-ruanjian-kaifa-campus)
