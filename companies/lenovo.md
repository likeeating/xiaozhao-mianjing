# 联想面经汇总：2 个岗位的面试题

按岗位整理的联想近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 联想](https://mianjingku.com/gongsi/lenovo)。

## 测试开发（校招）

- 收录：8 篇面经，79 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：实习深挖、Python 与 pytest、测试用例设计、计算机基础、英文表达、求职意向
- 示例题：
  - 怎么测试一个用户登录界面？
  - 一个 pytest 用例是怎么执行的？前置、执行、后置分别怎么做？
- 完整面经：[联想测试开发校招面经](https://mianjingku.com/mianjing/lenovo-ceshi-kaifa-campus)

## 嵌入式 / BIOS 开发（校招）

- 收录：8 篇面经，60 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面（部分部门）
- 常考方向：C 语言手撕、驱动与总线、I2C、操作系统、问题定位、位运算
- 示例题：
  - 工程题：把一条 I2C 总线上所有从设备的地址打印出来。
  - 读代码：一段带 continue 和 break 的 while 循环会执行几次？
- 完整面经：[联想嵌入式 / BIOS 开发校招面经](https://mianjingku.com/mianjing/lenovo-qianrushi-campus)
