# 携程面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的携程近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 携程](https://mianjingku.com/gongsi/ctrip)。

## 后端开发校招面经

- 收录：8 篇面经，97 道题
- 面试轮次：一面 · 技术面（项目 + 八股） → 二面 · 技术面或交叉面 → 三面 · 主管面（部分岗位） → HR 面
- 常考方向：项目深挖、Java 集合与 JVM、MySQL 与 Redis、消息队列、线上问题排查、系统设计
- 示例题：
  - CPU 使用率 100% 怎么排查？
  - 14 亿个名字，怎么统计重复次数最多的 TopK？
- 完整面经：[携程后端开发校招面经](https://mianjingku.com/mianjing/ctrip-houduan-campus)

## 产品经理校招面经

- 收录：3 篇面经，34 道题
- 面试轮次：一面 · 业务面（项目深挖） → 二面 · 业务面或交叉面 → HR 面
- 常考方向：项目深挖、数据与价值、产品感、行为面试、求职动机
- 示例题：
  - 怎么协调五个部门的负责人定下一个会议时间？
  - 项目前后的数据对比如何？有没有更细的粒度去定位项目带来的价值增量？
- 完整面经：[携程产品经理校招面经](https://mianjingku.com/mianjing/ctrip-chanpin-jingli-campus)
