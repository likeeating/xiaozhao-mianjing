# 阿里巴巴面经汇总：10 个岗位的面试题

按岗位整理的阿里巴巴近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 阿里巴巴](https://mianjingku.com/gongsi/alibaba)。

## 后端开发（实习）

- 收录：10 篇面经，191 道题
- 面试轮次：一面 · 技术面（八股 + 手撕） → 二面 · 技术面（实习项目 + 场景题） → 三面 · 技术面 / 主管面（部分团队） → HR 面
- 常考方向：Java 基础与并发、JVM 与 Spring、MySQL 与 Redis、场景设计、手撕算法、实习深挖
- 示例题：
  - ThreadLocal 的 key 为什么设计成弱引用？既然是弱引用还需要 remove 吗？如果 value 是弱引用呢？
  - 设计一个微信红包的金额分配方案。
- 完整面经：[阿里巴巴后端开发实习面经](https://mianjingku.com/mianjing/alibaba-houduan-intern)

## 测试开发（校招）

- 收录：8 篇面经，129 道题
- 面试轮次：简历评估面（部分部门） → 一面 · 技术面 → 二面 · 技术面 → 三面 · 技术 / 主管面（部分部门） → HR 面
- 常考方向：实习与项目深挖、测试用例设计、Java 基础、网络与操作系统、数据库与 SQL、手写代码
- 示例题：
  - 怎么测试一个水杯？
  - 页面出现白屏可能是什么原因？怎么排查？
- 完整面经：[阿里巴巴测试开发校招面经](https://mianjingku.com/mianjing/alibaba-ceshi-kaifa-campus)

## 产品经理（校招）

- 收录：8 篇面经，82 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → 三面 · 主管面或 HR 面
- 常考方向：简历深挖、产品分析、业务与行业认知、竞品分析、求职动机
- 示例题：
  - 项目里的竞品是谁？你们平时是怎么做日常运营的？
  - 分析一下钉钉和飞书的差异。
- 完整面经：[阿里巴巴产品经理校招面经](https://mianjingku.com/mianjing/alibaba-chanpin-jingli-campus)

## 产品经理（实习）

- 收录：8 篇面经，60 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → HR 面
- 常考方向：简历深挖、产品方向认知、业务理解、产品分析、个人经历与动机
- 示例题：
  - 产品经理分用户、平台、策略等很多种，你以后想做哪个方向？
  - 分享一个你常用的 App，说说为什么喜欢；如果让你改进它，会从哪些方面入手？
- 完整面经：[阿里巴巴产品经理实习面经](https://mianjingku.com/mianjing/alibaba-chanpin-jingli-intern)

## 后端开发（社招）

- 收录：8 篇面经，77 道题
- 面试轮次：一面 · 技术面 → 二面 · 直属主管面 → 三面 · 上级主管面 → HR 面 → 交叉面（部分岗位）
- 常考方向：项目深挖、Java 并发与 JVM、MySQL 与 Redis、消息队列、分布式与高并发、跳槽动机
- 示例题：
  - 服务分 10 批发布，第一批发完后负载很高、过一阵又恢复正常，可能是什么原因？怎么处理？
  - 怎么保证 Redis 和 MySQL 的数据一致性？
- 完整面经：[阿里巴巴后端开发社招面经](https://mianjingku.com/mianjing/alibaba-houduan-social)

## 前端开发（校招）

- 收录：8 篇面经，97 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：项目深挖、浏览器与缓存、网络与安全、React / Vue、工程化、手写题
- 示例题：

  - 虚拟列表里列表项高度不固定，怎么实现？
- 完整面经：[阿里巴巴前端开发校招面经](https://mianjingku.com/mianjing/alibaba-qianduan-campus)

- 收录：7 篇面经，105 道题
- 面试轮次：一面 · 技术面（基础 + 项目） → 二面 · 技术面（项目 + 场景设计 + 综合）

## 数据分析（校招）

- 收录：6 篇面经，68 道题
- 面试轮次：一面 · 电话专业面（常为突击） → 二面 · 专业面 → 终面 / 主管面 → HR 面
- 常考方向：指标异动归因、AB 实验与统计、费米估算、SQL、机器学习基础、项目深挖
- 示例题：

- 完整面经：[阿里巴巴数据分析校招面经](https://mianjingku.com/mianjing/alibaba-shuju-fenxi-campus)

## 算法工程师（校招）

- 收录：6 篇面经，57 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面（部分团队） → HR 面
- 常考方向：项目深挖、大模型基础、深度学习基础、推荐算法、Agent、手撕代码
