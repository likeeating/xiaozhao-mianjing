# 滴滴面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的滴滴近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 滴滴](https://mianjingku.com/gongsi/didi)。

## 后端开发校招面经

- 收录：8 篇面经，96 道题
- 面试轮次：一面 · 技术面（项目 + 八股 + 手撕） → 二面 · 技术面（实习深挖 + 场景设计 + 手撕） → 三面 · 技术面或主管面（部分岗位有四面）
- 常考方向：项目深挖、MySQL 索引、Redis 与缓存一致性、场景设计、手撕算法、AI 辅助研发
- 示例题：
  - 给定联合索引 (a, b, c)，判断 b=1 and a=2、c=1、a=1 and b>3 and c=4 这几条查询能否用上索引。
  - 手写：两个线程交替打印奇偶数到 100。
- 完整面经：[滴滴后端开发校招面经](https://mianjingku.com/mianjing/didi-houduan-campus)

## 算法工程师校招面经

- 收录：8 篇面经，76 道题
- 面试轮次：一面 · 技术面（项目 + 八股 + 手撕） → 二面 · 技术面 → 三面 · 技术面或主管面（部分有加面）
- 常考方向：项目深挖、Transformer 与注意力、大模型训练与对齐、机器学习基础、手撕算法、自动驾驶规控
- 示例题：
  - 详细介绍 GRPO 算法。
  - 1×1 卷积核有什么作用？
- 完整面经：[滴滴算法工程师校招面经](https://mianjingku.com/mianjing/didi-suanfa-campus)

## 产品经理校招面经

- 收录：5 篇面经，50 道题
- 面试轮次：一面 · 业务面（简历深挖 + 业务题） → 二面 · 业务面 → 三面 · 部门负责人面 → HR 面（部分年份没有）
- 常考方向：实习深挖、指标与数据、滴滴业务场景题、B 端与数据产品、产品感、自我认知
- 示例题：
  - 如果要优化一款打车软件，让它更吸引用户使用，你会怎么设计？
  - 你怎么理解数据产品？
- 完整面经：[滴滴产品经理校招面经](https://mianjingku.com/mianjing/didi-chanpin-jingli-campus)
