# 宝洁面经：秋招春招实习面试真题（4 个岗位）

按岗位整理的宝洁近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 宝洁](https://mianjingku.com/gongsi/pg)。

## 产品供应部（供应链管理）校招面经

- 收录：9 篇面经，86 道题
- 面试轮次：网申 + 在线测评（性格测试 + 速算 / 管道 / 记忆小游戏） → 一面 · 1v1（30–40 分钟） → 二面 · 3–4 位面试官（线上双机位或线下，45–65 分钟）
- 常考方向：宝洁八大问、项目与科研深挖、流程优化、情景题、求职动机、英文面试
- 示例题：
  - 讲一个你简化流程、提高效率的例子。（追问：优化点具体在哪里？）
  - 你手上的 A 任务已经排好计划，另一个部门的同事塞来一个一周内要完成的 B 任务，不久又来一个两天内要完成的 C 任务，你怎么处理？
- 完整面经：[宝洁产品供应部（供应链管理）校招面经](https://mianjingku.com/mianjing/pg-gongyinglian-campus)

## 客户生意发展（CBD）校招面经

- 收录：9 篇面经，73 道题
- 面试轮次：网申 + 在线测评（性格测试 + 职场情景选择 + 小游戏） → 一面 · 1v1（约 30 分钟） → 二面 · 3–4 位面试官（约 1 小时）
- 常考方向：宝洁八大问、经历深挖、情景题、求职动机、英文自我介绍
- 示例题：
  - 有没有教导别人的例子？别人说不会时，你倾向于亲手教还是给指导性建议？
  - 一项原定一个月后截止的工作突然要求 48 小时内完成，你怎么做？
- 完整面经：[宝洁客户生意发展（CBD）校招面经](https://mianjingku.com/mianjing/pg-xiaoshou-campus)

## 市场部（品牌管理）校招面经

- 收录：7 篇面经，51 道题
- 面试轮次：网申 + 在线测评（性格测试 + 数字 / 管道 / 记忆小游戏） → 一面 · 业务面（1–2 位面试官） → 二面 / 终面 · 多人面试（3–4 位面试官）
- 常考方向：宝洁八大问、经历深挖、英文面试、情景题、品牌营销、在线测评
- 示例题：
  - 市场规模有多大？多长时间能达到盈亏平衡（要给出具体数字）？
  - 情景题：新品马上要上市，突然发现竞品刚上了一款很相似的产品，你怎么办？
- 完整面经：[宝洁市场部（品牌管理）校招面经](https://mianjingku.com/mianjing/pg-shichang-yingxiao-campus)

## 产品供应部（供应链管理）实习面经

- 收录：3 篇面经，30 道题
- 面试轮次：网申 + 在线测评（性格测试 + 计算 / 管道 / 记忆小游戏） → 一面 · 1v1 → 二面 · 3–4 位面试官（可能含 HR）
- 常考方向：宝洁八大问、项目深挖、情景题、英文自我介绍、数据分析
- 示例题：
  - 你刚才一直说“我们”，你个人在这个项目里是什么角色、做了哪些努力？
  - 情景题（英文作答）：一个月的工作做了三周，老板突然要求 48 小时内完成，你怎么做？
- 完整面经：[宝洁产品供应部（供应链管理）实习面经](https://mianjingku.com/mianjing/pg-gongyinglian-intern)
