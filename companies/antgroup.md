# 蚂蚁集团面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的蚂蚁集团近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 蚂蚁集团](https://mianjingku.com/gongsi/antgroup)。

## 后端开发校招面经

- 收录：8 篇面经，122 道题
- 面试轮次：一面 · 技术面（实习 + 八股 + 手撕） → 二面 · 技术面 → 主管面 / HR 面
- 常考方向：实习深挖、Java 与 JVM、Spring、MySQL 事务与锁、计算机网络、Agent 工程
- 示例题：
  - 事务里的一致性和分布式系统里的一致性是一回事吗？
  - 如果让 Agent 完全接管整个写链路，你会怎么设计？
- 完整面经：[蚂蚁集团后端开发校招面经](https://mianjingku.com/mianjing/antgroup-houduan-campus)

## 算法工程师校招面经

- 收录：4 篇面经，51 道题
- 面试轮次：一面 · 技术面（项目 + 八股 + 手撕） → 二面 · 技术面 → HR 面
- 常考方向：强化学习与对齐、大模型基础、推荐与指标、项目深挖、手撕算法
- 示例题：
  - 有了 reward model 为什么还需要 critic model？critic model 起什么作用？
  - 为什么计算注意力时要缩放？怎么缩放？
- 完整面经：[蚂蚁集团算法工程师校招面经](https://mianjingku.com/mianjing/antgroup-suanfa-campus)

## 产品经理校招面经

- 收录：2 篇面经，21 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → HR 面
- 常考方向：实习深挖、商业化与指标、行业判断、金融与 AI、求职动机
- 示例题：
  - 大模型或 AI 技术可能给金融行业带来哪些变革？
  - 你怎么理解所在业务目前所处的阶段和面临的问题？
- 完整面经：[蚂蚁集团产品经理校招面经](https://mianjingku.com/mianjing/antgroup-chanpin-jingli-campus)
