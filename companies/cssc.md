# 中国船舶面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的中国船舶近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 中国船舶](https://mianjingku.com/gongsi/cssc)。

## 硬件工程师（含 FPGA）校招面经

- 收录：7 篇面经，58 道题
- 面试轮次：宣讲会 / 网申筛选 → 一面 · 技术面（多位专家） → 二面 · 综合面 / 主管面 → 科室意向沟通
- 常考方向：项目深挖、器件选型、PCB 与信号完整性、接口与单片机、信号调理与采集、城市意愿
- 示例题：
  - 信号隔离有哪些方式？为什么要做信号隔离？
  - 深挖一个项目：器件是怎么选型的？重点关注哪些参数？
- 完整面经：[中国船舶硬件工程师（含 FPGA）校招面经](https://mianjingku.com/mianjing/cssc-yingjian-campus)

## 嵌入式软件开发校招面经

- 收录：5 篇面经，50 道题
- 面试轮次：招聘会现场面 / 电话技术面 → 综合面 / 领导面 → 线下宾馆面或签约沟通
- 常考方向：项目深挖、RTOS 与操作系统、通信与网络、C 语言基础、个人情况、城市意愿
- 示例题：
  - Linux 和 FreeRTOS、RT-Thread 有什么区别？
  - 实习项目里，前期规划和后期实施时，软硬件接口是怎么规划的？
- 完整面经：[中国船舶嵌入式软件开发校招面经](https://mianjingku.com/mianjing/cssc-qianrushi-campus)

## 机械 / 结构设计校招面经

- 收录：3 篇面经，24 道题
- 面试轮次：网申 + 测评（行测、性格、心理） → 技术面 / 综合面 → 测评或填表 → offer / 签约
- 常考方向：项目与设计说明书、材料与选型、公差与工艺、个人背景、行业了解
- 示例题：
  - 工程图里的公差是怎么选的？没标公差的尺寸按什么公差处理？
  - 了解这家船厂吗？了解造船行业吗？
- 完整面经：[中国船舶机械 / 结构设计校招面经](https://mianjingku.com/mianjing/cssc-jixie-campus)
