# 德勤面经汇总：2 个岗位的面试题

按岗位整理的德勤近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 德勤](https://mianjingku.com/gongsi/deloitte)。

## 审计（校招）

- 收录：7 篇面经，64 道题
- 面试轮次：在线测评（GBA 等） → 群面 / AC（英文案例讨论） → 经理面（部分年份替代群面） → 合伙人面
- 常考方向：群面 / AC、英文案例、3 why、实习经历、审计认知、职业规划
- 示例题：
  - 你是不是把审计当跳板，最终想去金融行业？为什么不直接选金融？
  - 详细说说你未来几年在四大可能遇到的挑战，越多越好。
- 完整面经：[德勤审计校招面经](https://mianjingku.com/mianjing/deloitte-shenji-campus)

## 咨询（管理 / 财务 / 风险咨询）（校招）

- 收录：7 篇面经，69 道题
- 面试轮次：网申 + 在线测评（含写作 / 英文视频面） → 群面（英文案例；近年部分业务线不设） → 经理面（部分业务线两位经理连面，并现场做 Excel / AI 操作题） → 合伙人面
- 常考方向：群面 / 英文案例、3 why、行为面、岗位理解、简历深挖、英文面
- 示例题：
  - 这个岗位常招有 3–5 年审计经验的人，你打算怎么弥补这块短板？
  - 面对压力你会怎么处理？
- 完整面经：[德勤咨询（管理 / 财务 / 风险咨询）校招面经](https://mianjingku.com/mianjing/deloitte-zixun-campus)
