# 百度面经汇总：5 个岗位的面试题

按岗位整理的百度近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 百度](https://mianjingku.com/gongsi/baidu)。

## 测试开发（校招）

- 收录：8 篇面经，91 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面
- 常考方向：测试用例设计、自动化测试、SQL、计算机基础、AI 评测、手撕算法
- 示例题：
  - 针对“刷视频得奖励”这个功能设计测试用例。
  - Pytest 自带测试报告，为什么还要用 Allure？
- 完整面经：[百度测试开发校招面经](https://mianjingku.com/mianjing/baidu-ceshi-kaifa-campus)

## 产品经理（校招）

- 收录：8 篇面经，71 道题
- 面试轮次：一面 · 业务面 → 二面 · 业务面 → 三面 · 业务面 / 主管面
- 常考方向：简历深挖、AI 产品与大模型、数据指标与 AB 实验、产品设计、求职动机、业务理解
- 示例题：
  - 谈谈你对 Agent、RAG、Function Call 等技术的理解。
  - 你负责的产品用户活跃度突然下降，怎么定位和解决？
- 完整面经：[百度产品经理校招面经](https://mianjingku.com/mianjing/baidu-chanpin-jingli-campus)

## 后端开发（校招）

- 收录：8 篇面经，104 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面 → HR 面
- 常考方向：项目深挖、语言八股、MySQL、Redis 与消息队列、AI 应用与 Agent、手撕算法
- 示例题：
  - ReAct 模式的核心原理是什么？怎么避免它一直循环？
  - redo log、undo log 和 binlog 分别有什么作用？执行 update 时三种日志的写入顺序是怎样的？
- 完整面经：[百度后端开发校招面经](https://mianjingku.com/mianjing/baidu-houduan-campus)

## 后端开发实习生（实习）

- 收录：8 篇面经，113 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面
- 常考方向：项目深挖、Go / Java / C++ 基础、Redis、MySQL 索引、消息队列、场景题
- 示例题：
  - 一台服务器部署了多个 Go 服务，请求到达后怎么区分并转发？
  - 用 Zset 做排行榜时，要取某个分数区间内的用户，用什么命令？
- 完整面经：[百度后端开发实习生实习面经](https://mianjingku.com/mianjing/baidu-houduan-intern)

## 算法工程师（校招）

- 收录：7 篇面经，83 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · 技术面 / 主管面
- 常考方向：论文与项目深挖、大模型与强化学习、数据构建、Agent、手撕算法、AI 编程
- 示例题：
  - GRPO 的奖励函数是怎么设计的？分了哪些维度？怎么调优？
  - 为什么要设计三级记忆，单级不行吗？
- 完整面经：[百度算法工程师校招面经](https://mianjingku.com/mianjing/baidu-suanfa-campus)
