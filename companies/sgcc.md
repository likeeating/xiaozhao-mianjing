# 国家电网面经：秋招春招实习面试真题（3 个岗位）

按岗位整理的国家电网近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 国家电网](https://mianjingku.com/gongsi/sgcc)。

## 信息通信校招面经

- 收录：5 篇面经，36 道题
- 面试轮次：提前批：现场简历面（部分省份第一轮 10 人一组只做自我介绍） → 省信通提前批（湖南、浙江）：现场心理问卷测评 → 一面 2 对 1 简历面 → 部分省份二面 3 对 1 结构化（平板抽 3 道开放题） → 一批 / 二批：统一笔试后的结构化面试（约 15 分钟） → 在京直属单位：简历初面 → 技术面 → 笔试后正式面试
- 常考方向：简历与论文、结构化面试、志愿与调剂、求职动机、稳定性、AI 与电网
- 示例题：
  - 你怎么看待单位里的“小群体”现象？
  - 这个项目 的创新点是怎么想到的？是怎么实现的？为什么不用其他方法？
- 完整面经：[国家电网信息通信校招面经](https://mianjingku.com/mianjing/sgcc-xinxi-tongxin-campus)

## 电气工程校招面经

- 收录：3 篇面经，26 道题
- 面试轮次：统一笔试（行测 + 专业） → 结构化 / 半结构化面试（多对一） → 直属单位 / 提前批：技术面 + 人资面（部分单位）
- 常考方向：结构化面试、半结构化面试、电力系统专业题、服从分配、企业文化、简历深挖
- 示例题：
  - 如果把你分配到偏远地区，你会去吗？
  - SVC 和 SVG 有什么区别？
- 完整面经：[国家电网电气工程校招面经](https://mianjingku.com/mianjing/sgcc-dianqi-campus)

## 财务校招面经

- 收录：2 篇面经，16 道题
- 面试轮次：统一笔试 → 省公司：一轮结构化面试 → 直属单位：一面单面 → 二面多人同场 → 终面群面 + 追问
- 常考方向：结构化面试、会计基础、情景题、无领导小组讨论、求职动机
- 示例题：
  - 朋友有急事找你帮忙，可手头的工作走不开，你怎么处理？
  - 什么是往来账户？
- 完整面经：[国家电网财务校招面经](https://mianjingku.com/mianjing/sgcc-caiwu-campus)
