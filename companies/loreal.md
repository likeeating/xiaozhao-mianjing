# 欧莱雅面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的欧莱雅近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 欧莱雅](https://mianjingku.com/gongsi/loreal)。

## 管培生（MT）校招面经

- 收录：6 篇面经，61 道题
- 面试轮次：网申（行为类开放题）+ 测评 → 英文短视频 / 音视频测评 → 群面（个人作业 + 小组讨论 + 汇报 + HR 提问） → 业务面 / 品牌面（1–2 轮） → 终面 · 部门或事业部负责人
- 常考方向：网申开放题、英文表达、群面、品牌与产品理解、求职动机、经历深挖
- 示例题：
  - 描述一次你遭到他人反对、但你很清楚自己是对的经历：你具体说了什么、做了什么来达成共识？
  - 面试官拿出同一品牌的两款产品：你知道它们叫什么吗？差异在哪里、各自定价多少？如果由你来做营销，你会怎么做？
- 完整面经：[欧莱雅管培生（MT）校招面经](https://mianjingku.com/mianjing/loreal-guanpeisheng-campus)

## 市场营销（Marketing）实习面经

- 收录：4 篇面经，33 道题
- 面试轮次：网申开放题 / 测评 → HR 群面（部分人会被留下单面） → HR 面 / 业务面 → 品牌终面
- 常考方向：网申开放题、群面、品牌与行业理解、经历深挖、求职动机
- 示例题：
  - 分享一个你最喜欢的品牌，分析一下它为什么能火。
  - 假如现在这个品牌要找另一个品牌联名，你觉得选谁比较好？为什么？
- 完整面经：[欧莱雅市场营销（Marketing）实习面经](https://mianjingku.com/mianjing/loreal-shichang-yingxiao-intern)
