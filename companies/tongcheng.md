# 同程旅行面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的同程旅行近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 同程旅行](https://mianjingku.com/gongsi/tongcheng)。

## Java 后端开发校招面经

- 收录：8 篇面经，86 道题
- 面试轮次：一面 · 技术面（八股为主） → 二面 · 技术面（项目 + 场景）
- 常考方向：Java 并发、JVM、MySQL 索引、Redis、项目与场景设计、AI 工具使用
- 示例题：
  - 在线程池里执行异步任务时，怎么拿到提交任务那个线程的请求上下文？
  - 1000 万用户数据存在 MySQL，字段有用户名、手机号、昵称、兴趣等，查“叫 tom 的用户”时索引怎么设计？插入和查询时索引怎么生效？
- 完整面经：[同程旅行Java 后端开发校招面经](https://mianjingku.com/mianjing/tongcheng-houduan-campus)

## 测试开发校招面经

- 收录：4 篇面经，63 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 / 业务面
- 常考方向：实习深挖、接口自动化、测试用例设计、性能测试、SQL、问题排查
- 示例题：
  - 订票后 30 分钟不支付自动取消订单，从多个方向怎么设计测试用例？
  - 针对双十一的购物车场景，你会从哪些方面测试？
- 完整面经：[同程旅行测试开发校招面经](https://mianjingku.com/mianjing/tongcheng-ceshi-kaifa-campus)
