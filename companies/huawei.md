# 华为面经汇总：6 个岗位的面试题

按岗位整理的华为近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 华为](https://mianjingku.com/gongsi/huawei)。

## 硬件工程师（校招）

- 收录：11 篇面经，158 道题
- 面试轮次：机考 → 一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面
- 常考方向：项目深挖、电源设计、模电数电、接口与信号完整性、手画电路、主管面
- 示例题：
  - 项目的电源树是怎么设计的？效率如何？整板功耗怎么分析？
  - 你经历过最大的挫折或失败是什么？怎么走出来的？遇到问题会焦虑吗？
- 完整面经：[华为硬件工程师校招面经](https://mianjingku.com/mianjing/huawei-yingjian-campus)

## 软件开发（校招）

- 收录：10 篇面经，117 道题
- 面试轮次：机考（部分人免机考） → 一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面
- 常考方向：项目深挖、语言基础、操作系统与网络、手撕算法、主管面、华为文化
- 示例题：
  - 你在项目里主要负责什么？遇到过什么困难，是怎么解决的？
  - 手撕：用栈实现队列。
- 完整面经：[华为软件开发校招面经](https://mianjingku.com/mianjing/huawei-ruanjian-kaifa-campus)

## 财经专员（校招）

- 收录：7 篇面经，88 道题
- 面试轮次：一面 · 专业面 → 二面 · 专业面（常含英文环节） → 三面 · 业务主管面
- 常考方向：会计与报表、税务与财管、财务分析、英文表达、简历与课程深挖、外派意愿
- 示例题：
  - 三张财务报表之间的勾稽关系是怎样的？
  - 你能接受外派吗？
- 完整面经：[华为财经专员校招面经](https://mianjingku.com/mianjing/huawei-caiwu-campus)

## 算法工程师（校招）

- 收录：7 篇面经，74 道题
- 面试轮次：笔试 → 测评 → 一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面
- 常考方向：项目深挖、大模型与 Agent、深度学习基础、通信原理、手撕代码、主管面
- 示例题：
  - 讲讲 LoRA 微调的原理。
  - OFDM 的基本过程是怎样的？循环前缀起什么作用？
- 完整面经：[华为算法工程师校招面经](https://mianjingku.com/mianjing/huawei-suanfa-campus)

## 客户经理（校招）

- 收录：6 篇面经，61 道题
- 面试轮次：性格测评 + 英语测评 → 群面 · 无领导小组讨论 → 专业面 / 业务面 → 主管面
- 常考方向：无领导小组讨论、简历深挖、客户情景题、岗位理解、华为价值观、外派意愿
- 示例题：
  - 情景题：你去某地区接替一位客户经理，但他和当地客户关系很差，你怎么解决？
  - 你对客户经理这个岗位怎么理解？
- 完整面经：[华为客户经理校招面经](https://mianjingku.com/mianjing/huawei-xiaoshou-campus)

## 软件测试工程师（校招）

- 收录：5 篇面经，55 道题
- 面试轮次：机考 → 一面 · 技术面 → 二面 · 技术面 → 三面 · 主管面
- 常考方向：测试理解、测试方案设计、计网与 Linux、手撕代码、主管面
- 示例题：
  - 给你一个产品，你会怎么测试它？
  - 常用的 Linux 命令有哪些？
- 完整面经：[华为软件测试工程师校招面经](https://mianjingku.com/mianjing/huawei-ceshi-kaifa-campus)
