# 长安汽车面经汇总：3 个岗位的面试题

按岗位整理的长安汽车近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 长安汽车](https://mianjingku.com/gongsi/changan)。

## 机械 / 车辆工程（工艺、仿真、热管理等）（校招）

- 收录：8 篇面经，61 道题
- 面试轮次：一面 · 技术面（线上为主） → 二面 · 综合面 / HR 面（多为线下）
- 常考方向：项目与软件、行为面试题、优缺点与自我认知、重庆工作意愿、岗位调配、汽车基础
- 示例题：
  - 如果入职后领导觉得你更适合另一个研发岗位，你会怎么做？
  - 和上海相比，为什么选择去重庆工作？
- 完整面经：[长安汽车机械 / 车辆工程（工艺、仿真、热管理等）校招面经](https://mianjingku.com/mianjing/changan-jixie-campus)

## 软件开发（校招）

- 收录：6 篇面经，65 道题
- 面试轮次：一面 · 技术面 → 二面 · 综合面 / HR 面（多为线下）
- 常考方向：语言基础（C++ / Java）、操作系统与数据结构、数据库、设计模式、项目深挖、重庆工作意愿
- 示例题：
  - C++ 的多态是怎么实现的？
  - 工作地点在重庆，你是怎么考虑的？
- 完整面经：[长安汽车软件开发校招面经](https://mianjingku.com/mianjing/changan-ruanjian-kaifa-campus)

## 硬件工程师（电路 / 控制器 / 驱动）（校招）

- 收录：5 篇面经，53 道题
- 面试轮次：一面 · 技术面 → 二面 · 综合面（多为线下）
- 常考方向：电源与模拟电路、项目深挖、MCU 与软件基础、汽车与控制器认知、工作地点意愿、行为与开放题
- 示例题：
  - 画出 BUCK 和 BOOST 的拓扑图，讲讲它们的工作原理。
  - 如果分配到以写 C 语言为主的岗位，你怎么看？
- 完整面经：[长安汽车硬件工程师（电路 / 控制器 / 驱动）校招面经](https://mianjingku.com/mianjing/changan-yingjian-campus)
