# 奇安信面经汇总：3 个岗位的面试题

按岗位整理的奇安信近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 奇安信](https://mianjingku.com/gongsi/qianxin)。

## 前端开发（校招）

- 收录：7 篇面经，72 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：Vue 原理、JavaScript 基础、浏览器与网络、前端安全、项目经历、手撕代码
- 示例题：
  - 客户反馈页面白屏（不一定是你写的代码），你怎么排查？如果不能埋点、也没有日志呢？
  - Vue2 和 Vue3 的响应式原理有什么区别？Vue3 解决了哪些问题？Vue2 的数组问题怎么处理？
- 完整面经：[奇安信前端开发校招面经](https://mianjingku.com/mianjing/qianxin-qianduan-campus)

## C++ 开发（校招）

- 收录：4 篇面经，45 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 / 主管面 → HR 面
- 常考方向：C++ 基础、编译与调试、操作系统、网络编程、思维题、手撕代码
- 示例题：
  - 某个函数调用到一定次数后程序会崩溃，又不能重新编译，怎么找出是第几次？
  - 协程是怎么实现的？和线程切换有什么不同？
- 完整面经：[奇安信C++ 开发校招面经](https://mianjingku.com/mianjing/qianxin-ruanjian-kaifa-campus)

## 后端开发（Java / Go）（校招）

- 收录：3 篇面经，45 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → HR 面
- 常考方向：Redis 与缓存、MySQL、Go 语言、Java 与 Spring、认证与加密、手撕代码
- 示例题：
  - Redis 的 MULTI 能保证原子性吗？MULTI/EXEC 和 Lua 脚本有什么区别？
  - 非对称加密有哪些算法？RSA 有什么优缺点？
- 完整面经：[奇安信后端开发（Java / Go）校招面经](https://mianjingku.com/mianjing/qianxin-houduan-campus)
