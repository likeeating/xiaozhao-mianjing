# 微博面经汇总：2 个岗位的面试题

按岗位整理的微博近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 微博](https://mianjingku.com/gongsi/weibo)。

## 后端开发（校招）

- 收录：4 篇面经，72 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面 → 三面 · leader 面（部分部门） → HR 面
- 常考方向：语言基础、操作系统与网络、Redis 与数据库、系统设计、手写代码、项目深挖
- 示例题：
  - 如果让你设计微博：共同好友、查看关注者更新这些功能怎么做？数据库怎么设计？
  - 场景题：一个很大的日志文件，怎么找出访问次数最多的前 3 个 IP？
- 完整面经：[微博后端开发校招面经](https://mianjingku.com/mianjing/weibo-houduan-campus)

## 客户端开发（Android / 移动端）（校招）

- 收录：2 篇面经，34 道题
- 面试轮次：一面 · 技术面 → 二面 · 技术面
- 常考方向：Java 并发、Android 组件原理、性能优化、计算机基础、手写代码
- 示例题：
  - ViewModel 的生命周期比 Activity 长，这是怎么实现的？为什么 Activity 销毁后 ViewModel 还在？
  - 为什么想做移动端？未来的工作规划是什么？
- 完整面经：[微博客户端开发（Android / 移动端）校招面经](https://mianjingku.com/mianjing/weibo-kehuduan-campus)
