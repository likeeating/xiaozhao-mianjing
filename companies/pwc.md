# 普华永道面经：秋招春招实习面试真题（2 个岗位）

按岗位整理的普华永道近期面经：每个岗位列出面试轮次、常考方向和两道示例题。完整题目在 [面经库 · 普华永道](https://mianjingku.com/gongsi/pwc)。

## 审计校招面经

- 收录：7 篇面经，58 道题
- 面试轮次：网申 + 在线测评 → Superday · 破冰 + 案例群面 → Superday · 经理和合伙人单面
- 常考方向：Superday、英文破冰、案例群面、简历深挖、审计动机、行为面
- 示例题：
  - 你的实习里没有审计经历，为什么想做审计？
  - 你觉得上午的小组讨论你们组表现如何？和另一组相比有什么优缺点？
- 完整面经：[普华永道审计校招面经](https://mianjingku.com/mianjing/pwc-shenji-campus)

## 税务校招面经

- 收录：3 篇面经，26 道题
- 面试轮次：网申 + 在线测评 + 视频面（VI） → Superday · 破冰 + 案例群面 → Superday · 个人即兴演讲（税务特有） → Superday · 合伙人面 → 春招部分组别（如转让定价）：只有一轮合伙人 + 高级经理的 2 对 1 面试
- 常考方向：Superday、案例群面、即兴演讲、英文表达、求职动机、合伙人面
- 示例题：
  - 即兴演讲：你怎么看“地摊经济”？
  - 我为什么应该给你 offer？
- 完整面经：[普华永道税务校招面经](https://mianjingku.com/mianjing/pwc-shuiwu-campus)
